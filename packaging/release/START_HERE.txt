Bugs Bunny & Taz: Time Busters Recompiled @VERSION@
(ready-built package)

A native PC version of the PlayStation game, with Daffy Duck as a third
playable character and up to three players, each on their own PC.

YOU NEED
- Windows 10 or 11 (64-bit).
- Your own copy of the game disc as a disc image: the .cue file and its
  .bin file(s) of Bugs Bunny & Taz: Time Busters (USA). No game data and no
  retail BIOS are included (OpenBIOS is bundled). A .chd image starts too,
  but only .cue + .bin can play together with others.

FIRST START (once)
1. Right-click the ZIP -> "Extract All..." -> Extract. Do not start the game
   from inside the ZIP: it cannot find its files there and cannot keep your
   settings or saves. Keep the folder somewhere ordinary, like Desktop or
   Documents (not Program Files).
2. In the extracted folder, double-click BugsBunnyTaz_Recompiled.exe.
   If Windows says "Windows protected your PC": click "More info", then
   "Run anyway". (The game is not signed with a paid certificate, so
   Windows asks about it.)
3. The launcher asks for your disc: choose your .cue file. It checks that
   it is the original USA disc.
4. Your controller: on the first screen, card PLAYER 1, choose it below
   the controller picture (Configure changes the buttons).
   Then PLAY.

Nothing needs to be set in Mods. Out of the box:
- Quick start: the game opens on its main menu (English; other languages
  in Mods); in a LAN room the players come from the room (no ONE / TWO
  PLAYERS menu); no long intro, short loading screens.
- Own view: in a match, every PC shows its own player full screen.
- Third player: Daffy Duck joins when a third player is there (three
  seated in a LAN room; on one PC, once Player 3 presses a button, from
  the next level start). With two players he stays away.
- Decorations are off. To hang a Turkish flag from the windows of Granny's
  house: Mods -> Decorations.
- The picture is drawn in true colour, without the PlayStation's dither
  pattern. To bring it back: Mods -> Image Filtering, turn it on, then
  Dithering = Native (PS1).

PLAYING TOGETHER (over the internet with Radmin VPN, or on a home LAN)
Details: PLAYING_TOGETHER.md. In short:
- Everyone uses this same ZIP. Over the internet everyone installs Radmin
  VPN and joins the same Radmin network.
- Host: NETPLAY -> LAN / Direct IP -> Host Lobby -> Create Lobby.
  Guests: NETPLAY -> LAN / Direct IP -> Join Direct with the host's Radmin
  IP (26.x.x.x) and port 7777.
- When Windows Defender Firewall asks about the game: tick both "Private"
  and "Public" networks, then "Allow access". Without this the others
  cannot reach the host.
- The host presses PLAY when everyone is seated (two or three players).
- In the game: NEW GAME -> START GAME. Seat 1 is Bugs, seat 2 Taz, seat 3
  Daffy.

SAVES
A match is played on the host's memory card, so the host keeps the
campaign. Each guest also keeps a copy of it (saves/netplay/card1.mcd); to
continue the same campaign as host later, first copy that file to a new
name (e.g. saves/campaign.mcd), then pick the copy for memory card 1 in the
launcher's Memory Card panel (Browse). Not the file itself: the next match
you join as a guest writes the host's card into it.

Your settings and saves are in this folder. When updating to a new
version, extract it to a new folder and copy your saves/ folder (and
keybinds.ini, if you changed keys) into it; the launcher asks for the disc
once more.
