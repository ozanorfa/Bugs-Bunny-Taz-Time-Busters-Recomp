Bugs Bunny & Taz: Time Busters Recompiled @VERSION@

A native PC version of the PlayStation game, with Daffy Duck as a third
playable character and up to three players, each on their own PC.

1. You need your own copy of the game disc (Bugs Bunny & Taz: Time Busters,
   USA). No game data and no retail BIOS are included; OpenBIOS is bundled.
2. Start BugsBunnyTaz_Recompiled and choose your disc image (.cue) when
   asked. The launcher checks that it is the original USA disc.
3. Controls: Settings -> Input in the launcher. On your own PC your own
   gamepad or keyboard is your player.

Nothing needs to be set in Mods. Out of the box:
- Quick start: the game opens on its main menu (English; other languages
  in Mods); in a LAN room the players come from the room (no ONE / TWO
  PLAYERS menu); no long intro, short loading screens.
- Own view: in a match, every PC shows its own player full screen.
- Third player: Daffy Duck joins when a third player is there (three
  seated in a LAN room). With two players he stays away.

Playing together (LAN or Radmin VPN): see PLAYING_TOGETHER.md. In short:
- Host: NETPLAY -> LAN / Direct IP -> Host Lobby -> Create Lobby.
  Guests: NETPLAY -> LAN / Direct IP -> Join Direct with the host's IP.
- The host presses PLAY when everyone is seated (two or three players).
- In the game: NEW GAME -> START GAME. Seat 1 is Bugs, seat 2 Taz, seat 3
  Daffy.

Saves: a match is played on the host's memory card, so the host keeps the
campaign. Each guest also keeps a copy of it (saves/netplay/card1.mcd); to
continue the same campaign as host later, pick that file for memory card 1
in the launcher's Memory Card panel (Browse).

Keep your saves/ folder and settings when updating the application.
